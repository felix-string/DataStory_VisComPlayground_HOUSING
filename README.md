# Student Housing Affordability Gap in Germany

This repository contains the report, presentation, data and visualisations for our Visual Communication and Data Storytelling project.

## Project focus

The project investigates differences in asking rents across selected German university cities. It examines whether university cities that were previously relatively affordable are experiencing faster rental growth.

## Main question

How is the student housing affordability gap changing across German university cities?

## Data

The project uses GREIX rental market data, including median asking rents, average asking rents, rental price indices and inflation-adjusted measures.

The data represent the wider private rental market rather than student-only accommodation.

## Main outputs

- Quarto HTML report
- Quarto Revealjs presentation
- Reproducible data visualisations
- Cleaned analysis data
